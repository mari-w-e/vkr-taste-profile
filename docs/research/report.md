### Выводы по обзору

Наиболее распространённый метод рекомендаций — коллаборативная фильтрация. Он требует большого объёма данных об оценках пользователей [6, 7], которых у нового сервиса нет. Поэтому в работе используется подбор по характеристикам позиций каталога и профилю пользователя [6, 11]. При этом у нового пользователя профиль отсутствует, пока он сам не укажет свои предпочтения [11].

Для описания вкуса кофе существует общепринятый словарь — колесо вкусов SCA [5]. Его можно использовать как основу для вкусовых характеристик в каталоге.

Большие языковые модели позволяют обрабатывать предпочтения, описанные пользователем своими словами, и формировать понятные объяснения без дополнительного обучения модели [1, 2, 9]. Открытым остаётся вопрос, как связать свободное описание вкуса с характеристиками позиций каталога. Решению этого вопроса посвящена данная работа.

## 3. Обзор и сравнение аналогов

### Прямые аналоги

- **Trade Coffee** (https://www.drinktrade.com). Сервис подписки на кофе: пользователь проходит короткую анкету, после чего ему подбирается кофе от партнёрских обжарщиков. Подбор уточняется по оценкам пользователя. Ограничения: сервис работает только в США и не поддерживает русский язык; предпочтения выбираются из готовых вариантов ответа; подбор ограничен ассортиментом сервиса.
- **Статьи-руководства «Как выбрать кофе»** (например, https://www.gazeta.ru/social/news/2026/08/18/29130457.shtml, https://profile.ru/?p=1402740). Объясняют, как вид зерна, обработка и обжарка влияют на вкус. Ограничения: дают общие рекомендации без учёта вкуса конкретного человека; пользователь должен сам сопоставить советы с описанием на упаковке; не сохраняют информацию о том, что пользователю понравилось.

### Косвенные аналоги

- **Vivino** (https://www.vivino.com). Приложение для выбора вина: формирует вкусовой профиль по оценкам пользователя и показывает процент совпадения для каждого вина. Ограничения: работает только с вином; нельзя описать вкус своими словами; совпадение указывается процентом без пояснения.
- **Чат-боты на основе ИИ (GigaChat, ChatGPT и др.)**. Отвечают на вопросы о кофе на естественном языке. Ограничения: не опираются на каталог, поэтому могут давать неточные сведения; не хранят структурированный вкусовой профиль пользователя.

### Таблица сравнения

**Почему выбраны эти критерии:** критерии отражают основные трудности пользователя при выборе кофе: он не знает профессиональных терминов, не может понять описание на упаковке и не помнит, что ему понравилось ранее.

### Выводы по сравнению

Ни один из аналогов не объединяет все рассмотренные возможности. Сервисы подбора (Trade Coffee, Vivino) учитывают оценки пользователя, но не позволяют описать вкус своими словами и не объясняют результат. Статьи-руководства дают только общие советы. Чат-боты понимают свободный текст, но не опираются на каталог и не хранят профиль пользователя.

Разрабатываемый сервис объединяет эти возможности: пользователь описывает вкус своими словами, система подбирает кофе из каталога, объясняет выбор и уточняет профиль по оценкам.

### Актуальность исследования

Выбор продуктов питания и напитков — повседневная задача, которая при этом зависит от множества факторов [3, 4]. На упаковках кофе указываются профессиональные характеристики (регион, обработка, обжарка, вкусовые ноты), которые непонятны большинству покупателей. Существующие решения либо дают общие советы, либо недоступны в России, либо не опираются на проверенные данные. Развитие больших языковых моделей позволяет обрабатывать описания вкуса на естественном языке [1, 2]. Это делает возможным создание доступного сервиса, который помогает пользователю выбрать кофе с учётом его вкуса и объясняет сделанный выбор.

### Цель исследования

Разработка веб-сервиса, обеспечивающего формирование вкусового профиля пользователя и персонализированный подбор позиций на основе анализа его предпочтений с применением технологий искусственного интеллекта.

### Задачи исследования

1. Проанализировать существующие решения в области персонализированного подбора и выявить их ограничения.
2. Разработать модель вкусового профиля пользователя и структуру каталога (на примере кофе).
3. Разработать алгоритм персонализированного подбора на основе вкусового профиля.
4. Реализовать модуль анализа текстовых описаний предпочтений пользователя и характеристик позиций с применением ИИ.
5. Провести тестирование сервиса и оценить качество подбора.

### Датасеты и сервисы

- **Собственный каталог** (около 50 позиций кофе) с характеристиками: регион, обработка, обжарка, вкусовые ноты, способ заваривания. Формируется на основе открытых описаний производителей.
- **Coffee Taster's Flavor Wheel (SCA/WCR)** — основа словаря вкусовых характеристик. https://worldcoffeeresearch.org
- **API большой языковой модели** (GigaChat или YandexGPT) — анализ текстовых описаний и формирование объяснений. Дополнительное обучение модели не требуется.
- **Данные пользователей** — оценки и описания предпочтений, собираемые при тестировании прототипа.
